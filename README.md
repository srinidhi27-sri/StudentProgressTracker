# Student Progress Tracker System

## About the Project
The Student Progress Tracker System is a Java Swing desktop application designed to manage student academic information, marks, attendance, and progress reports in one place.

## Objectives
- Manage student registration details.
- Record and calculate student marks and grades.
- Track student attendance and eligibility.
- Generate academic progress reports.
- Integrate a database using JDBC for persistent storage.

## Technologies Used
- Java
- Java Swing
- JDBC (database integration)
- MySQL or another database selected by the team

## Current Features
- Dashboard
- Student Registration
- Marks Management
- Attendance Management
- Progress Reports

Frontend screens are implemented. Database integration and persistent data storage are the next steps.

## How to Run
1. Install the Java Development Kit (JDK).
2. Open the project folder in VS Code.
3. Compile the Java files from the project root:

   ```bash
   javac screens/Dashboard.java screens/StudentRegistration.java screens/MarksManagement.java screens/AttendanceManagement.java screens/ProgressReports.java
   ```

4. Run the application:

   ```bash
   java screens.Dashboard
   ```
